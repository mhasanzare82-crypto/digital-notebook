# دفتر دیجیتال من - نسخه ویندوز

این پروژه بر اساس فایل HTML ارائه‌شده ساخته شده و با Electron بسته‌بندی می‌شود.
خروجی CI شامل فایل نصب‌کننده NSIS و نسخه قابل‌حمل است.

## ساخت خروجی بدون نصب ابزار روی کامپیوتر شخصی

1. وارد https://github.com شوید و یک حساب کاربری بسازید یا وارد شوید.
2. یک مخزن جدید (New repository) بسازید؛ نام پیشنهادی `digital-notebook` است.
3. فایل ZIP پروژه را در رایانه استخراج کنید.
4. تمام محتویات پوشه پروژه، از جمله پوشه مخفی `.github`، را به مخزن GitHub بارگذاری و Commit کنید.
   - اگر با بارگذاری وبی GitHub کار می‌کنید، مطمئن شوید پوشه `.github/workflows` و فایل `build-windows.yml` هم بارگذاری شده‌اند.
5. در مخزن، زبانه Actions را باز کنید.
6. گردش‌کار `Build Windows applications` را انتخاب و روی `Run workflow` کلیک کنید.
7. پس از پایان موفق، وارد اجرای انجام‌شده شوید و از بخش Artifacts فایل `DigitalNotebook-Windows11` را دانلود کنید.
8. ZIP دانلودشده را باز کنید. داخل آن دو فایل EXE قرار دارد:
   - `...Setup...exe`: نصب برنامه؛
   - `DigitalNotebook-Portable-1.0.0.exe`: اجرای مستقیم بدون نصب.

## نکات

- برای دریافت وابستگی‌ها و اجرای GitHub Actions اتصال اینترنت لازم است.
- این خروجی x64 برای ویندوز ۱۱ معمولی (۶۴ بیتی) تنظیم شده است.
- فایل‌ها امضای دیجیتال ناشر ندارند؛ ممکن است Windows SmartScreen هشدار ناشر ناشناس نمایش دهد. فقط فایل ساخته‌شده از مخزن خودتان را اجرا کنید.
- نسخه فعلی برای OCR فارسی و بارگذاری Tesseract از CDN به اینترنت نیاز دارد.
- داده‌ها در فضای ذخیره‌سازی محلی مرورگر Electron نگهداری می‌شوند. پیش از حذف برنامه یا پاک‌سازی داده‌های برنامه، از اطلاعات مهم نسخه پشتیبان تهیه کنید.
- این پروژه هنوز قابلیت همگام‌سازی ابری یا پشتیبان‌گیری خودکار ندارد.
